# 🤖 Machine Learning

A collection of **Machine Learning implementations and experiments** using Python, covering various supervised and unsupervised learning techniques, data preprocessing, feature selection, dimensionality reduction, and model development.

This repository contains implementations and practical exercises using several machine learning algorithms and datasets, including classification, regression, clustering, and feature extraction.

## 🚀 Topics & Algorithms

* 🌳 **Decision Tree** — Classification using decision tree algorithms.
* 📊 **Naive Bayes** — Probabilistic classification using Naive Bayes.
* 📈 **Regression** — Regression model implementation and analysis.
* 🎯 **Support Vector Machine (SVM)** — Classification using Support Vector Machines.
* 🔵 **K-Means Clustering** — Unsupervised clustering using K-Means.
* 🟣 **K-Modes Clustering** — Clustering for categorical data.
* 🧩 **Feature Selection** — Feature selection using Chi-Square.
* 📉 **Dimensionality Reduction** — Feature extraction using PCA and LDA.
* ⚖️ **Imbalanced Data** — Handling and analyzing imbalanced datasets.
* 🧹 **Data Preprocessing** — Data preparation and transformation for machine learning models.

## 🧠 Machine Learning Methods

### 🌳 Decision Tree

Decision Tree is used to build classification models by recursively splitting data based on selected features.

The implementation can be found in:

```text
decision-tree/
decision_tree.py
```

### 📊 Naive Bayes

Naive Bayes is implemented as a probabilistic classification approach based on Bayes' theorem and the assumption of feature independence.

```text
naive-bayes/
```

### 📈 Regression

The `regresi/` directory contains implementations and experiments related to regression-based machine learning.

```text
regresi/
```

### 🎯 Support Vector Machine

```text
svm/
```

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

* Python 3.x
* Git

### 1. Clone the Repository

```bash
git clone https://github.com/shendytria/Machine-Learning.git
cd Machine-Learning
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

Activate the virtual environment.

**Windows:**

```bash
venv\Scripts\activate
```

**macOS / Linux:**

```bash
source venv/bin/activate
```

### 3. Install Dependencies

Install the required Python libraries:

```bash
pip install numpy pandas scikit-learn matplotlib
```

Additional libraries may be required depending on the specific project or algorithm being executed.

## ▶️ Running the Projects

Individual Python scripts can be executed using:

```bash
python nama_file.py
```

For example:

```bash
python kmeans_mall.py
```

or:

```bash
python decision_tree.py
```

Some implementations may require the corresponding dataset to be available in the project directory.
